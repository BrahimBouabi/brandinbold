## 3. Architecture Overview

### 3.1 BrowserEngine Interface
`electron/engine/BrowserEngine.ts` — UNCHANGED contract (user rule 3):
```ts
interface BrowserEngine {
  readonly id: EngineId; readonly name: string
  installedVersion(): Promise<string | null>
  ensureInstalled(onProgress?): Promise<void>
  launch(profile, userDataDir, ipInfo | null): Promise<{ result: LaunchResult; handle: BrowserHandle }>
}
```
`BrowserHandle`: `{ pid, debugPort, remote, cookies:{export,import,clear?}, openUrl(url), stop() }`.

- **CamoufoxEngine** — `electron/engine/camoufox/CamoufoxEngine.ts` — default, **done, verified** (native C++ fingerprinting, cross-OS font fix, badge addon, wrapper bundles, session restore, purge on stop, ownership-aware sync writes n/a here). Uses `launchOptions()` + `firefox.launchPersistentContext()` (playwright-core).
- **ChromeCdpEngine** — `electron/engine/ChromeCdpEngine.ts` — fallback, done (CDP + JS-injection spoofing lives only here).
- **ChromiumEngine ("BoldBrowser")** — ❌ not started; interface ready.

### 3.2 Data Layer
- **Local**: SQLite `~/Library/Application Support/Brandinbold/rea.db` — tables `profiles(id,name,status,group_id,deleted_at,created_at,updated_at,json)`, `groups(id,name,pinned,color,description,created_at)`, `proxies`, `settings(key,value)` (AppSettings JSON).
